# 快眠ナイトルーティン逆算シミュレーター

希望の就寝時間から、お風呂・食事・スマホオフなどの最適なタイミングを逆算し、今夜の行動スケジュールを作成するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/sleep-prep-scheduler/）。
2. 画面の指示に従って操作します。
